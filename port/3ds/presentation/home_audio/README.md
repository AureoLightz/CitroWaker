# Original HOME Menu sound

`generate.py` creates `citrowaker-highlight.wav` using only mathematical sine oscillators and envelopes: three original bell tones, no game recording or melody transcription. Stereo signed 16-bit PCM, 32 kHz, 2.7 seconds. Original project code/audio under MIT.

The CIA packager now uses this file instead of `cia/highlight3s.wav`. Repackaging and reinstalling the CIA is required to change an already installed title. Old local game-music files are retained for development history but are no longer referenced by the packager.
