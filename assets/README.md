# Showcase assets

The two Outset PNGs are unmodified 400 × 240 captures of the development port running in Azahar on November 12, 2026: the Outset Island bridge and coast. ending-timing.png is one frame of the ending cutscene from the same build in Azahar, scaled to 800 pixels wide by the showcase tool, with its measured frame-time footer. They are gameplay screenshots, not mockups, and are not evidence of real-console image quality or performance. Nintendo retains rights to the game imagery.

citrowaker.svg is an original typographic project banner. No extracted game texture, model, font, music, disc image, save or generated game-data pack is included here. This directory does not grant a licence over Nintendo assets or the wider project.
